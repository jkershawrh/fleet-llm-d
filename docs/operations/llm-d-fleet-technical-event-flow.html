C. Router beta transport internals

Discovery files

multicluster-file-discovery watches a model-specific endpoint file. Entries contain address/port and labels for cluster ID, exact model, health, failure domain, metrics address/port, TLS server name, trust ref, and auth ref. Files are deterministic and atomically published; index.json is published last.

Envoy + EPP

EPP returns x-gateway-destination-endpoint. Envoy uses it for host rewrite and dynamic SNI, verifies backend TLS using the mounted Route CA bundle, and strips destination headers before the backend sees the request. failure_mode_allow: false prevents bypass if ext_proc/EPP fails.

Execution evidence

For the Router path, the gateway maps X-Fleet-Router-Upstream back to an exact model/provider. If it does not belong to the fleet-qualified set, the gateway drains the response and returns 502 routing_evidence_mismatch.

E. What is asynchronous and therefore potentially stale

30-second publication window

Agent/repository state is rendered on the controller ticker. A provider can fail between snapshots. Active probes/SWIM narrow detection; the single pre-header CPU retry masks one stale selection.

Signals are advisory

Missing queue/KV/load data does not invent values. Selection falls back to qualified health/capacity. Readiness must not be disguised as queue or KV utilization.

GPU remains non-HA

Brutus is the only exact Granite 8B provider. Its loss intentionally produces 503 no_compatible_capacity; it is never silently rewritten to the CPU model.
