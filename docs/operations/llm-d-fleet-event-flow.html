llm-d-fleet event flow

Four distinct paths: synchronous inference, asynchronous qualification, health/capacity signals, and optional governed evidence.

Inference requestControl-plane stateHealth/load signalOptional evidence
Critical boundaryThe synchronous path never waits on DeepField, GCL, or a central management hub.
Exact-model ruleCompatibility filtering occurs before EPP scoring. Brutus loss yields an explicit GPU 503.
Retry ruleAt most one bounded CPU retry before headers; never retry after streamed bytes.
Ownership ruleFleet qualifies globally; Router/EPP scores locally; KServe owns serving lifecycle.
